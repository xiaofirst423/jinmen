JinmenTitle.woff是用于本网页题字的字符子集（约7KB），保留原字形，未修改笔画。子集字符：津门清咽音浪假日草本有声分享现场收下开箱好礼。正文和功能控件使用系统常规字体。若修改题字文字，应重新生成子集或使用许可允许的完整字体。

使用fontTools.subset生成：`pyftsubset LXGWWenKai-Regular.ttf --text="津门清咽音浪假日草本有声分享现场收下开箱好礼" --flavor=woff --output-file=JinmenTitle.woff`。此工具仅用于维护字体，运行网页无需Python。
