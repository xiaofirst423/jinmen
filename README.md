# 津门清咽音浪假日 · 草本音浪 H5

七页手机网页，采用 React 19、CSS、JavaScript 和 Vite。文字、按钮与主视觉分离；手机直接呈现H5，电脑居中显示手机内容与活动背景。无需数据库和真实登录。

在线演示：[津门清咽音浪假日](https://xiaofirst423.github.io/jinmen-qingyan-h5/)。源码仓库：[xiaofirst423/jinmen-qingyan-h5](https://github.com/xiaofirst423/jinmen-qingyan-h5)。

本地开发地址为 http://localhost:4173/ 。同一局域网手机可使用开发服务器显示的网络地址访问，以本机网络地址为准。

## 使用交付包

解压后，在 Windows 中双击 `启动演示.cmd`，保持窗口运行，然后访问 http://localhost:4173/ 。需要Node.js 20.19+；当前电脑可自动使用Codex自带Node。预先构建的 `dist/client` 已包含所需脚本、样式和图片，不需要安装依赖。

不要直接双击 `index.html`：浏览器需要通过本地HTTP服务加载JavaScript模块与资源。

## 页面与演示流程

- 首页：活动主视觉、开箱主入口、四项活动、奖励预览、精选互动。
- 音浪开箱官：指定话题复制、四级奖励、周榜、投稿与重提。
- 积分任务与福利：签到、任务领取、每周/每日上限、四档兑换与记录。
- 清咽16.2秒返场挑战：参与指南、指定话题、奖励、视频链接与购买证明。
- 护嗓搭子：晒单、购买截图、笔记@好友、双方奖励及邀请进度。
- 我的参与：投稿分类、审核状态、身份、积分记录和空状态。
- 我的权益：券、实物、会员/抽奖资格与领取、兑换记录。

电脑右侧为“比赛演示控制”；手机在页尾或内页右上角打开。可模拟通过、黄金通过、未通过、空参与记录和恢复初始数据。黄金通过使用201点赞、50收藏，以演示黄金奖励及两项任务领取。

推荐演示：投稿→我的参与待审核→演示控制模拟审核→奖励到账→福利页领取任务积分→兑换→我的权益领取。未通过记录可补充材料重新提交。800积分兑换的是1次门票抽奖资格；钻石周榜门票及返场周纪录奖励展示规则，不假装发放真实门票。

余额、签到、投稿、邀请、兑换、领取与积分明细保存在本机localStorage。上传只校验图片类型/大小并展示文件名，不上传、不长期保存原始文件。审核是明确标注的人工模拟；没有社媒核验或真实券核销。

## 修改与开发

- `src/App.jsx`：七页组件、路由、表单、弹窗、演示控制。
- `src/ui.css`：颜色、排版、手机/电脑布局、微交互、减少动态支持。
- `src/model.js`：奖励、积分、任务、审核、兑换与领取状态逻辑。
- `public/assets/`：主视觉、原视觉稿中真实品牌与奖励素材。
- `tests/flows.test.mjs`：规则与主要状态测试。
- `design-qa.md`、`qa/browser-check.json`：目视与浏览器验证结果。

安装依赖后启动开发服务（支持npm或pnpm）：

```sh
pnpm install
pnpm dev --host 0.0.0.0 --port 4173 --strictPort
pnpm test
pnpm build
```

也可使用 `npm install`、`npm run dev`、`npm test`、`npm run build`；使用npm时先运行install生成其依赖锁。构建产物位于 `dist/client`。现成静态服务器可用 `node scripts/serve.mjs` 启动。

## GitHub Pages 自动发布

向main分支推送更新后，`.github/workflows/pages.yml`会安装锁定依赖、运行规则测试、构建并部署到GitHub Pages。也可在Actions页面手动运行。Pages使用GitHub Actions作为部署源，构建目录为`dist/pages`，仓库子路径由`VITE_BASE_PATH`自动设置。

本地核验Pages构建：

```powershell
$env:VITE_BASE_PATH='/jinmen-qingyan-h5/'
pnpm run build:pages
```

网页公开可访问；投稿、积分与领奖仍是浏览器本机的演示状态，不接入真实服务。

## 已验证与范围

九项规则测试通过。Chrome无界面浏览器完成七页×320/390/430px共21组布局检查，验证无横向溢出、图片加载、底部遮挡和核心交互，控制台无错误。另检查1400×1000电脑布局。未在真实iOS Safari上验证。

规则以已购用户社交媒体二次触达机制设计Word为准。开箱满30减10、搭子满30减15均保留14天；5元无门槛券不新增有效期。白银/黄金分别为点赞>50/>200，积分兑换100/300/600/800。活动起止日期未提供，不编造日期或疗效保证。商城、购物车、支付不纳入本演示。
