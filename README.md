## 页面与流程

- 主导航始终为“首页 / 福利 / 我的”；内页吸顶“返回首页”，支持浏览器后退和`#/openbox`等深链接。
- 首页恢复带原品牌logo、主标题和草本音乐场景的一体营销海报，搭配真实可点击的深绿圆角参加按钮、话题复制、金色基础券卡与独立现场照片；剪贴板不可用时显示可选中复制的完整话题。返场挑战、护嗓搭子仍收在“更多玩法”，不恢复密集四格入口。
- 开箱：发布指南 → 满30减10基础奖励 → 必填作品链接与声明 → 原位成功结果。标题、截图选填折叠；完整奖励阶梯与周榜按需展开。
- 福利：积分、签到、任务与兑换优先；详细规则、积分明细与兑换记录按需查看。
- 我的：轻量身份与积分、我的奖励入口、参与记录；保留优惠券、其他奖励及领取记录。查看新券定位待领取；返场成功后查看奖励直接打开“其他奖励”，会员资格可见。
- 返场挑战与搭子晒单仍需作品链接、购买证明；搭子可填好友账号。

推荐体验：首页 → 参加开箱征集 → 填写已发布作品链接并确认 → 提交成功（基础券与积分明确展示）→ 查看奖励 → 返回首页。所有三类活动提交后即通过，无需演示控制或手动审核。

## 数据与规则

浏览器本地存储键仍为`jinmen-herbal-holiday-v1`，内部版本升为2。原版积分、投稿、权益、兑换与积分明细保留；旧待审、未通过投稿一次转为通过，并按原数据达标情况补发未发奖励。发奖标记、稳定奖励ID及积分明细ID共同防重。示例初始360积分与5项权益保留，三条示例投稿统一为通过。

新投稿点赞和收藏固定从0开始，忽略传入的互动量，不直接获得高阶奖励。同一活动的相同作品链接（忽略片段与末尾斜线）或重复投稿ID不会再次保存、发奖、加分。发布开箱笔记每周仅一次50积分。积分每周获得上限500，签到每天5分，互动每天最多10分；点赞达到100、收藏达到50分别可每周领取30分。精选入选300分与周榜奖保留规则展示，当前示例不自动发放。

白银点赞严格>50，黄金严格>200；钻石为周榜TOP10。兑换100/300/600/800积分，其中800只给1次门票抽奖资格。开箱满30减10与搭子满30减15券均14天；5元无门槛券不新增有效期。搭子好友奖励不会进入本人账户。

损坏存储会恢复可用演示状态；存储读写被禁用或额度不足时仍可在当前页面体验，页顶和成功结果会提示刷新可能丢失。各浏览器、域名和端口的本地数据彼此隔离；迁移须在原访问来源下进行。上传只校验类型/大小并保存文件名，不上传或长期保存图片原件。未接入真实审核、社媒核验、支付、发券或券核销，演示奖励无真实兑换效力。

## 开发与验证

安装Node.js及pnpm后，运行`pnpm install --frozen-lockfile`，以`pnpm dev --host 0.0.0.0 --port 4173 --strictPort`开发。也可使用npm安装依赖和运行对应脚本。
